 # 7-Day Canadian Weather Data Analysis
This project analyzes 7-day historical weather data across major Canadian cities to uncover weather trends and vacation-friendly regions.
Data was collected using the WeatherAPI and stored in AWS S3 via a scheduled AWS Lambda trigger. 
The analysis includes temperature, wind, rainfall, daylight duration, and more, with insights visualized in an interactive Power BI dashboard.

## Tools & Technologies: 

**Languages:** Python (Pandas, Numpy, Requests, Matplotlib, Seaborn)

**Frameworks & Services:** AWS Lambda, AWS S3, Google Colab

**Visualization:** Power BI

**APIs:** WeatherAPI.com
